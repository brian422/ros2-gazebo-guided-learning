# Learning review

## Scope of my participation

I followed introductory ROS 2 lessons using Codex as an AI tutor, ran the
provided rover code, and studied the interaction between simulated sensor
data, odometry, control commands, and mission logic. This was guided learning,
not independently authored robotics software.

## Questions for continued study

These are review prompts, not claims of demonstrated mastery or completed
independent modifications.

1. How do nodes, topics, and services differ?
2. Which process publishes odometry, and which node consumes it?
3. What connects a robot model to the coordinate frames shown in RViz?
4. How do position and heading error affect the example's velocity commands?
5. What changes when a control gain or waypoint tolerance changes?
6. Why does displaying lidar not by itself provide obstacle avoidance?
7. How does the mission state change after a hazard or invalid sensor input?
8. What do the supplied unit tests check, and what requires a running simulator?
9. How do CSV summaries differ from synchronized raw sensor records?
10. What additional knowledge would be needed to design a similar system independently?

Future notes can record a specific observation, its supporting command or
capture, and the explanation in my own words. No additional debugging story,
code authorship, or personal experimental result is asserted here.
